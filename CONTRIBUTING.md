# Contributing

Thanks for stopping by! This repository is primarily a **personal Data Analytics & AI knowledge management system** — a single source of truth for one person's learning roadmap, technologies, projects, and career prep. It isn't a typical open-source project looking for feature pull requests, but a few kinds of contributions are genuinely welcome.

## What's welcome

- 🐛 **Bug reports** — broken links, typos, or outdated badges. Please [open an issue](../../issues).
- 💡 **Suggestions** — a resource, dataset, or project idea that fits an existing folder. Open an issue describing it.
- 🍴 **Forking** — if this folder structure is useful for your own learning system, fork it freely (MIT licensed).

## What's off-limits

- ❌ **Structural changes.** The 9 top-level categories (`01_Learning` through `09_Certifications`) and their subfolders are **frozen**. Pull requests that rename, move, or restructure folders will not be merged.
- ❌ **Unrelated content.** This repository stays scoped to Data Analytics, Data Engineering, and AI learning material.

## How to suggest something

1. Check [existing issues](../../issues) to avoid duplicates.
2. Open a new issue with a clear title and, where relevant, which folder it relates to.
3. For typos/broken links, a pull request is fine — keep the diff small and scoped to the fix.

## Code of conduct

Be respectful and constructive. This is a learning space, not a battleground.
